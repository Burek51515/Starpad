# Contributing to Starpad

Thank you for considering contributing to Starpad! 🚀

## Ways to Contribute

- 🐛 Report bugs
- 💡 Suggest features
- 📝 Improve documentation
- 🔧 Submit code fixes
- 🎨 Improve UI/UX
- 🔒 Report security issues

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/yourusername/starpad.git`
3. Create a branch: `git checkout -b feature/your-feature`
4. Make changes
5. Test thoroughly
6. Commit: `git commit -m "Add your feature"`
7. Push: `git push origin feature/your-feature`
8. Open Pull Request

## Code Style

### Rust
- Follow standard Rust conventions
- Run `cargo fmt` before committing
- Run `cargo clippy` and fix warnings
- Add tests for new features

### TypeScript/JavaScript
- Use Prettier for formatting
- Follow ESLint rules
- Write clear comments
- Add JSDoc for functions

### Git Commits
- Use present tense ("Add feature" not "Added feature")
- Use imperative mood ("Move cursor to..." not "Moves cursor to...")
- Limit first line to 72 characters
- Reference issues: "Fix #123"

## Testing

Before submitting PR:
- [ ] All tests pass: `anchor test`
- [ ] No linting errors
- [ ] Test on devnet
- [ ] Update documentation

## Security Issues

**DO NOT** open public issues for security vulnerabilities.

Email: security@starpad.io

See [SECURITY.md](SECURITY.md) for bug bounty details.
